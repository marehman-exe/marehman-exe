### Hi there

I'm an AI engineer who started out in data analysis and e-commerce, where I learned how much real business decisions depend on data. That pushed me toward machine learning and software engineering. I now work remotely building RAG systems and LLM agents, and I'm finishing my Computer Science degree.

**What I build**

- **Retrieval systems that cite their sources.** LexBase is a multi-tenant legal RAG system: hybrid search (pgvector with HNSW, plus keyword search merged by Reciprocal Rank Fusion), citation validation on every answer, per-firm data isolation, JWT auth with refresh-token rotation, and prompt-injection defenses. Backend in FastAPI and PostgreSQL, frontend in React and TypeScript.
- **LLM agents with guardrails.** Three LangChain and LangGraph agents: an email assistant that needs human approval before acting, a multi-agent wedding planner that turns one sentence into flights, venues and a playlist, and a multi-turn personal chef that searches the web for real recipes.
- **Applied ML with honest evaluation.** [Waze churn](https://github.com/marehman-exe/Wase---User-Churn-Prediction) (~15K records, tuned for recall), [TikTok claim vs. opinion](https://github.com/marehman-exe/Tiktok---Claim-and-Opinion-Classification) (~19K records), and [taxi tip prediction](https://github.com/marehman-exe/Automatidata---Generous-Tip-Prediction) (~22.7K records, leakage-aware target). Also an [interpretable card-scoring engine](https://github.com/marehman-exe/PTCG-AI-Deck-Intelligence-Strategy-Engine) for the Pokémon TCG, an [Arabic character-level language model](https://github.com/marehman-exe/Google-DeepMind---Train-A-Small-Language-Model), and [SightShield](https://github.com/marehman-exe/SightShield), my final year project: a Raspberry Pi smart belt with real-time object detection for visually impaired users.
